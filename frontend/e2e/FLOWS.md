# Flow inventory

The checklist the browser tests are measured against (docs/web-ui-test-plan.md, section 8).
Each row names its tests; a row without one is a known gap. Test titles start with the row's ID
(`test('NAV-03 …')`), so a failure points back here. Update this file in the same change as
the tests.

Status: **done** (every behaviour in the row has a test), **partial** (some), blank (none).

A known gap in the app is a test of the right behaviour marked `test.fail(true, 'known gap …')`:
it runs and is expected to fail, so the suite stays green, and Playwright reports it the
moment the gap is fixed (then remove the `test.fail`).
